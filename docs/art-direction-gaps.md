# 던전 청소부 슬라임군 — 부족한 연출/디자인 채우기 브리프

> 이 문서는 PixelLab API 생성용이 **아닙니다.** 직접 손으로 그리실 때 참고하는 디자인 스펙입니다.
> 기존 `슬라임 청소부 — 픽셀 에셋 보드`(캐릭터/아이템/재화/환경/UI 키트)와 기획서(4개 Scene 구성)를 맞춰봤을 때,
> **보드에는 없지만 게임에는 반드시 필요한 화면·연출·상태**만 추려서 정리했습니다.
> 기존 보드에 이미 있는 것(슬라임 4종, 아이템 8종, 재화 아이콘, 환경 타일, 소환버튼/등급배지 등)은 다시 언급하지 않습니다.

## 0. 픽셀 규칙 (기존 보드 그대로 준수)

- 아웃라인: 모든 스프라이트 1px 짙은 남색(`#1A1020`) 외곽선
- 셰이딩: 3단계(하이라이트/베이스/그림자), 그라디언트·블러 금지(조명 효과 예외 반투명 허용)
- 기준 해상도: 아이템/아이콘 16×16, 캐릭터 20×17, 타일 16×16 (화면 1280×720 = 320×180 기준 1px→4px)
- UI 박스: 외곽선 4 → 그림자 4 → 하이라이트 4 → 본문 (9-slice)
- 등급 색상(재사용): Normal `#CFC8B6` · Rare `#3088FF` · Epic `#A75CF0` · Unique `#F2C23A` · Legendary `#FF4D4D`

## 2. 신규 화면 목업 (우선순위 순)

### 2-1. Scene 2 게임화면 전체 레이아웃 ★최우선
실제로 플레이 시간 대부분을 보내는 화면인데 보드엔 부품(아이콘)만 있고 배치가 없습니다.
- **상단바**: 좌측 골드 아이콘+숫자, 가운데 레벨+EXP 바(초록 진행바 재사용), 우측 소환개수 `12/40` (성장의 나무 아이콘 옆 배치)
- **중앙 슬라임 뷰**: 슬라임 몸속 배경 — 반투명 연두색 젤리 질감, 안쪽 아이템들이 둥둥 떠 있는 느낌. 배경은 어둡게, 아이템 실루엣이 도드라지도록 대비
- **우측 패널**: 아이템 구매 목록(스톤 패널 재사용) — 아이템 아이콘 + 가격 + 잠금 여부(자물쇠 아이콘 재사용)
- **우상단**: 스킬트리 진입 버튼(작은 "성장의 나무" 아이콘 버튼), 대출 진입 버튼(신규 아이콘 필요 — 아래 4-3 참고)

### 2-2. 청소 진행 링 (아이템 위 오버레이) ★최우선
아이템이 청소되는 동안 진행률을 보여줄 장치가 보드에 없습니다.
- 아이템 아이콘(16×16) 테두리를 감싸는 얇은 원형 게이지, 시계방향으로 채워짐
- 색상: 진행 중 초록(`#4CAF50`), 90% 이상일 때 노랑 깜빡임으로 "곧 완료" 표시
- 완료 순간 링이 반짝(스파클 FX 재사용)하며 사라짐

### 2-3. Scene 3 스킬트리 화면
버튼 하나가 아니라 실제 트리 형태가 필요합니다.
- 4개 스킬(자동청소 속도/성공확률/문지르기 속도/보상증가)을 노드 4개로 배치, 노드 사이 연결선(양피지 패널 배경 위에 갈색 선)
- 노드 상태 3종: 잠김(회색+자물쇠), 강화 가능(테두리 반짝임 강조), 최대 레벨(금색 테두리)
- 각 노드 옆에 `현재 레벨 / 최대 레벨` 표기, 상단에 보유 포인트 표시(성장의 나무 아이콘 + 숫자)

### 2-4. Scene 4 대출 화면 (완전 신규)
보드에 이 씬 관련 요소가 하나도 없습니다.
- 부채 게이지 바(빨간색 계열, 대출한도 대비 현재 부채 비율)
- 이자 타이머: 다음 복리 적용까지 남은 시간(모래시계 아이콘 재사용 + 카운트다운 숫자)
- "대출받기" / "상환하기" 버튼 2종 (소환버튼과 같은 스타일, 색만 파랑/초록으로 재사용 가능)
- 부채가 대출한도에 근접하면 게이지가 붉게 경고 깜빡임

### 2-5. 결과창 (런 종료 요약)
- 획득 코어, 획득 골드, 청소한 아이템 수, 플레이타임 4개 항목을 양피지 패널 위에 아이콘+숫자로 나열
- 상단에 "결과" 타이틀 배너, 하단에 "확인" 버튼

### 2-6. 일시정지 메뉴 / 설정 화면
- 일시정지: 스톤 패널 위에 "계속하기 / 설정 / 메인으로" 3버튼 세로 배치
- 설정: 마스터/BGM/SFX 슬라이더 3개(가로 바 + 손잡이), 저사양 이펙트 토글 스위치, 데이터 초기화 버튼(빨간 계열, 위험 강조)

### 2-7. 메인 타이틀 화면
- 로고 타이포(기획서의 "Do Hyeon" 스타일 참고) + 슬라임 캐릭터 대형 버전(대기 포즈 확대)
- 배경: 던전 입구 실루엣 (환경 타일 조합으로 구성 가능 — 벽돌 벽면 + 횃불 반복 배치)
- "게임 시작 / 설정 / 종료" 세로 버튼 3개

## 3. 연출/이펙트 (지금은 LEGENDARY 버스트 1종뿐)

| 이펙트 | 트리거 | 방향 |
|---|---|---|
| 청소 성공 | 성공 판정 순간 | 아이템이 반짝이며(스파클 FX) 골드 숫자가 위로 튀어오르는 텍스트(`+N`) |
| 단순 실패 | 실패 판정 순간 | 아이템이 흐려지며(알파 감소) 회색 연기 파티클과 함께 사라짐 |
| 파괴 | 파괴 판정 순간 | 아이템이 조각나며(파편 2~3개) 붉은 손실 텍스트(`-N`)와 함께 사라짐 |
| 레벨업 | EXP 가득 참 | 슬라임 전체가 노란 빛으로 잠깐 번쩍, "LEVEL UP!" 배너(보드의 LEGENDARY! 타이포 재사용) |
| 스킬 강화 | 포인트 소비 | 노드가 반짝이며 연결선이 순간적으로 밝아짐 |

## 4. 상태/아이콘 보강

### 4-1. 슬라임 표정 배리에이션
현재 대기/청소중 2종뿐입니다. 추가로:
- 성공 시 기쁜 표정(눈 반달 모양)
- 실패/파괴 시 놀란 표정(눈 커짐)
필요하면 기존 슬라임 스프라이트에 눈 부분만 교체하는 식으로 최소 작업 가능.

### 4-2. 토글 스위치
설정 화면용 On/Off 스위치 — 소환버튼과 같은 톤(초록 On / 회색 Off), 가로 캡슐형

### 4-3. 대출 아이콘
상단바/게임화면에서 대출 화면 진입 버튼으로 쓸 아이콘 — 동전 뭉치 위에 계약서/저울 모티프, 재화 아이콘들과 같은 16×16 톤

### 4-4. 확인 모달 (데이터 초기화 등 위험 액션)
양피지 패널보다 작은 팝업, 빨간 테두리 강조, "취소/확인" 버튼 2개

## 5. 작업 순서 제안

크레딧/시간 제약을 고려하면 이 순서를 추천합니다:

1. **2-1, 2-2** (게임화면 레이아웃 + 진행 링) — 없으면 플레이 자체가 불가능한 핵심
2. **3. 이펙트 3종(성공/실패/파괴)** — 코어 루프의 피드백이라 체감 임팩트가 큼
3. **2-3, 2-4** (스킬트리/대출 화면) — 기획서상 필수 Scene이지만 코어 루프 다음 우선순위
4. **2-5, 2-6, 2-7** (결과창/일시정지/설정/타이틀) — 있으면 완성도가 높아지지만 없어도 프로토타입 플레이는 가능
5. **4. 상태/아이콘 보강** — 여유 있을 때 디테일 마감
