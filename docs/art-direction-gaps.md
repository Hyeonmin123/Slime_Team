# 던전 청소부 슬라임군 — 실제 화면 기준 에셋 갭 정리

> **정정**: 이전 버전은 픽셀 에셋 보드 이미지만 보고 기획서와 대조해서 쓴 추측성 문서였고, 실제 화면(Figma)을 확인하지 않고
> "없다"고 단정한 부분이 다수 틀렸습니다. 아래는 사용자가 공유한 Figma 스크린 13장(Screen 00~08, 튜토리얼 1~4)을
> 실제로 보고 다시 정리한 내용입니다.

## 0. 실제로 이미 완성되어 있는 것 (전부 확인함)

| 화면 | 상태 |
|---|---|
| Screen 00 타이틀 | 완성 — 로고 타이포, 배경(횃불+벽), 슬라임 대기 포즈, 시작/이어하기/설정/크레딧 버튼 |
| Screen 01 메인 플레이 | 완성 — 상단바(골드/코어/타이머/도전과제?/성장의나무/런종료), 좌측 "칸 강화" 패널, 중앙 소환마법진+아이템+슬라임들, 우측 소환확률 리스트(등급별 %), 하단 소환버튼/대기열/저장소 게이지 |
| Screen 02 성장의 나무 | 완성 — **실제 트리 구조**(로마숫자 티어 I~IV, 분기 노드, 연결선, 카테고리 탭 5개: 소환/이동/청소/운반/골드), 노드 상세 패널(비용/설명/부족 코어 표시) |
| Screen 03 런 결과 | 완성 — 획득 코어(기본+보너스 분리 표기), 골드/청소개수/시간/최고등급 4분할, 등급별 무기 획득 개수 스트립, 미회수 아이템 경고 배너, 성장의나무/새 런 버튼 |
| Screen 04 도감 | 완성 — 아이템×등급 그리드(미발견 `?` 처리), 선택 아이템 상세(설명/판매가/골드환산/발견횟수), 수집률 바, 페이지네이션 |
| Screen 05 설정 | 완성 — 사운드 3종 슬라이더(마스터/배경음/효과음, 수치 표시), 이펙트 감량 토글, 데이터초기화/크레딧/닫기 버튼 |
| Screen 06 일시정지 | 완성 — 계속하기/설정/튜토리얼 다시보기/타이틀로 나가기 4버튼, 자동저장 체크박스, 경고 문구 |
| Screen 07 튜토리얼 1~4 | 완성 — 4단계 온보딩(소환→청소→수거→성장), 각 단계 아이콘 조합, 진행 dot, 건너뛰기/다음 버튼 |
| Screen 08 엔딩 | 완성 — 완료 배너, 슬라임 2종 연출, 6개 통계(플레이시간/청소무기수/도달층/해금노드/런수/누적코어), 크레딧, 타이틀로 |

**결론: 화면 레이아웃 자체는 다 있습니다.** 이전 문서에서 "Scene별 화면 목업이 없다"고 한 건 전부 취소합니다.

## 1. 확인이 필요한 것 (제가 단정 못 하는 부분)

- **아이템 "청소 진행" 표시 방식**: Screen 01에서 각 아이템에 원형 링이 개별적으로 있는지는 이 스크린샷(보상 팝업이 뜬 순간)만으로는 명확히 안 보입니다. 화면 중앙에 긴 초록 막대바가 하나 있는데, 이게 (a) 현재 청소 중인 아이템 하나의 진행률인지, (b) 층 전체/다음 층까지의 진행률인지, (c) 둘 다 따로 있는데 이 프레임엔 안 겹쳐 보이는지 구분이 안 됩니다. 실제 청소 진행 중(팝업 없는 평상시) 프레임 스크린샷을 하나 더 보여주시면 정확히 확인하겠습니다.

---

## 2. 실제로 빠진 것 (신규로 그려야 할 에셋)

기존 픽셀 에셋 보드(슬라임 4종/아이템 8종/재화아이콘/환경타일/UI키트)와 이번에 확인한 실제 화면을 대조한 결과, 진짜 없는 건 이 정도입니다 — 이전 문서보다 훨씬 적습니다.

### 2-1. 스킬 카테고리 아이콘 5종 (신규, 우선순위 최상)
Screen 01 좌측 "칸 강화" 패널과 Screen 02 스킬트리 탭에 **양쪽 다 쓰이는** 아이콘인데 보드에 없습니다: **소환 / 이동 / 청소 / 운반 / 골드** 5개. 16×16, 보드 톤 유지. (골드는 기존 골드 코인 아이콘 재사용 가능해서 사실상 4종 신규)

### 2-2. 토글 스위치 (On/Off)
Screen 05 "이펙트 감량"에 사용. 가로 캡슐형, On=초록/Off=회색 — 소환버튼 색 재사용 가능.

### 2-3. 볼륨 슬라이더 트랙 + 손잡이
Screen 05 사운드 3종에 사용. 기존 진행바 스타일에 드래그 가능한 손잡이(thumb) 그래픽만 추가하면 됨.

### 2-4. 체크박스 (선택/미선택)
Screen 06 "자동저장 진행 계속하기"에 사용. 작은 정사각 체크박스, 새 에셋.

### 2-5. SPACE 키캡 아이콘
Screen 07 튜토리얼 1/4에 사용. 키보드 스페이스바 형태의 작은 아이콘.

### 2-6. 경고/위험 패널 톤
Screen 03 "미회수 아이템" 배너, Screen 05 "데이터 초기화" 버튼 강조용. **새로 그릴 필요 없음** — 기존 스톤 패널을 `recolor.mjs`로 빨간 계열로 로컬 무료 변환하면 됩니다.

### 2-7. 페이지네이션 화살표(◀▶)
Screen 04 도감 하단. 아주 작은 UI 요소, 새로 그리거나 기존 화살표 폰트로 대체 가능.

### 2-8. 슬라임 피킹(엿보기) 포즈
Screen 03 결과창 우하단에 슬라임이 화면 밖에서 빼꼼 보이는 연출. 있으면 좋지만 없어도 무방(우선순위 낮음).

## 3. 결론 / 작업 순서

실제로 필요한 신규 작업은 **2-1(카테고리 아이콘 5종)** 하나가 사실상 핵심이고, 나머지(2-2~2-5)는 각각 하나씩만 그리면 되는 작은 UI 부품입니다. 2-6은 그릴 필요 없이 로컬 변환으로 해결됩니다.

1. 스킬 카테고리 아이콘 5종 (소환/이동/청소/운반/골드)
2. 토글 스위치, 슬라이더 손잡이, 체크박스, SPACE 키캡 — 각 1개씩
3. (선택) 슬라임 피킹 포즈, 페이지네이션 화살표

**청소 진행 표시 방식은 위 1번 확인 후 필요하면 추가하겠습니다.**
